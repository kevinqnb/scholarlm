## Session 2026-09-26

### Prompts

- Create a new MeasurementLM ablation, `MeasurementLMAblation7`, removing the
  standardization, parse-qualifiers, and deduplication steps. Qualifier
  fields should be output as null; records should still be identified by a
  measurement id, and produce a clean set of records for
  `analysis/match_cache.py`. Add a path for running it via
  `experiments/run_ablation.py`. Then write experiment configs for ablation 7
  across all three extraction models (llama-3.1-8b, gemma-3-27b,
  gpt-oss-120b) and all four datasets (pond, nfix, supermat, measeval).

### Implemented

Added `src/scholarlm/measurementlm_ablation7.py`: `MeasurementLMAblation7`
overrides only `_standardize()` (units left untouched, no LLM call),
`_parse_quantities()` (every qualifier/shape field written null, no LLM
call), and `_deduplicate()` (identity -- no merging); `fit()` and steps 1-6
are inherited unchanged from the base pipeline. This is the same "qualifiers
unfilled" shape `analysis/postprocessing.py` already fills from the raw
value/standardizes units for afterward -- no eval-path code changed.
Registered as `"7"` in `run_ablation.py`'s `ABLATION_REGISTRY`. Added 4 unit
tests (`tests/test_measurementlm_ablation7.py`); full suite 944 passed, 1
skipped. Wrote and verified (config-load, dry-run submit) 12 full-run
experiment configs, one per (dataset, model) pair across
pond/nfix/supermat/measeval x llama-3.1-8b/gemma-3-27b/gpt-oss-120b under
`experiments/experiment-configs/<dataset>/ablation/2026-09-26-<dataset>-ablation7-<model>-full-01/`.
Ablation 7 has no runtime precedent, so walltimes are grounded as the max of
each pair's own existing ablation 2/3/4/6 walltimes (all genuine full-pipeline
runs via `run_ablation.py`), rather than an invented number. None of the 12
configs have passed rung 3 (tiny end-to-end) yet -- do not submit before it
does.
